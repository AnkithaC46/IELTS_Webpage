# IELTS Mastery Institute Homepage

A clean, modern, and professional homepage for a fictional IELTS preparation institute, built using **React** and **Tailwind CSS**. This project focuses on converting provided content into reusable, responsive components.

---

## 🚀 Key Features

This project utilizes the following core features as defined in the content brief:

1.  **Student-Centric Hero:** A strong CTA driving enrollment.
2.  **Feature Cards:** Highlighting key differentiators like **AI-Powered Band Score Prediction** and **Live Speaking Practice**.
3.  **Testimonial Slider:** Showcasing success stories from high-scoring students (Band 7.5+).
4.  **Responsive Layout:** Fully optimized for desktop, tablet, and mobile viewing using Tailwind CSS.

---

## 🛠️ Tech Stack

* **Framework:** React
* **Styling:** Tailwind CSS (utility-first approach)
* **Icons:** Lucide React

---

## ⚙️ Setup and Installation

Follow these steps to get the project running locally:

### Prerequisites

You must have **Node.js** and **npm** (or yarn/pnpm) installed on your machine.

### 1. Clone the Repository

```bash
git clone https://github.com/AnkithaC46/IELTS_Webpage.git
cd IELTS
```

### 2. Install Dependencies
Install the required packages, including React and Tailwind CSS dependencies.


```Bash
npm install
npm install recharts lucide-react react-icons
```

### 3. Run the Development Server
Start the application in development mode. It will typically open on http://localhost:3000.

```Bash
npm run dev
